**[GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** 可在云端异步运行。你可以在 GitHub 上分配工作，cloud agent 会在后台接手任务，探索存储库、进行更改并创建拉取请求；与此同时，你可以处理其他事情。

在这些练习中，你将添加 cloud agent 会遵循的自定义指令，然后分配一个 GitHub 议题，让它实现相应工作。你还将审查并使用自定义智能体来调整其工作方式，在智能体仪表板中监控和引导会话，最后审查它创建的拉取请求并迭代改进结果。

## 先决条件

参加本研讨会前，请确保具备以下条件：

- [ ] 拥有 GitHub 账户，并已启用 **Copilot Student、Pro、Pro+、Business 或 Enterprise** 计划
- [ ] 已为你的账户或组织启用 Copilot cloud agent

> [!TIP]
> 没有付费计划？通过验证的学生可以通过 [GitHub Education][callout-student-plan-education] 免费使用 GitHub Copilot。**Copilot Student** 计划包含本研讨会使用的智能体、MCP、代码审查和 Copilot CLI 功能，因此可以用它完成所有工作环境的学习路径。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> 除 Copilot Free 外，Copilot Student、Pro、Pro+、Business 和 Enterprise 均可使用 cloud agent。对于 Copilot Business 或 Enterprise，管理员必须为组织启用此功能。

> [!NOTE]
> 本工作环境不涉及 MCP。若要了解如何将 MCP 服务器与 Copilot 搭配使用，请参阅 [CLI 工作环境][cli-harness]或 [VS Code 工作环境][vscode-harness]。
