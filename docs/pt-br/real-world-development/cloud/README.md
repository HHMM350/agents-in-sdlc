O **[agente de nuvem do GitHub Copilot](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** permite que o GitHub Copilot trabalhe de forma assíncrona na nuvem. Você atribui tarefas no GitHub, e o agente de nuvem as executa em segundo plano — explora o repositório, faz mudanças e abre um pull request — enquanto você realiza outras atividades.

Nestes exercícios, você adicionará instruções personalizadas para orientar o agente de nuvem, atribuirá uma issue do GitHub e deixará que ele implemente o trabalho. Você revisará e usará agentes personalizados para definir a abordagem, monitorará e orientará as sessões no painel de agentes e, por fim, revisará os pull requests e iterará sobre os resultados.

## Pré-requisitos

Antes de participar deste workshop, confira se você tem:

- [ ] Uma conta do GitHub com um plano ativo **Copilot Student, Pro, Pro+, Business ou Enterprise**
- [ ] O agente de nuvem do Copilot habilitado para sua conta ou organização

> [!TIP]
> Não tem um plano pago? Estudantes verificados podem obter o GitHub Copilot gratuitamente pelo [GitHub Education][callout-student-plan-education]. O plano **Copilot Student** inclui o agente, MCP, revisão de código e Copilot CLI usados neste workshop — assim, você pode concluir todos os percursos com esse plano.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> O agente de nuvem está disponível nos planos **Copilot Student, Pro, Pro+, Business e Enterprise** — todos, exceto o Copilot Free. No Copilot Business ou Enterprise, um administrador precisa habilitá-lo para a organização.

> [!NOTE]
> Este percurso não aborda MCP. Para aprender a usar servidores MCP com o Copilot, consulte o percurso da [CLI](../cli/) ou do [VS Code](../vscode/).
